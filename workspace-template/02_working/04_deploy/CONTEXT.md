# Stage contract, 04 Deploy

Purpose: hand over a running solution.

Inputs: the tested components, the promoted PRD, the test evidence.

Outputs, written to output\ in this folder:
- Deployment record (what shipped where, versions, solution export reference).
- Handover notes and operations contacts.
- Any client-facing runbook.

Exit criteria:
1. Solution live in the target environment.
2. Handover accepted by the client.

Gate: engagement close, human sign off.
